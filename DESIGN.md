# Design Guidelines for this project

## Prioritize responsive design

The interface must always take into account phone, tablet and monitor screen sizes and addapt acordingly.

## Design Direction

This is a portfolio page for a developer with passion for games and technology and it should reflect that.

## Color Scheme

It should use mainly shades of black blue and some highlights in white use the mochkai logo (public/images/logo.svg) as a reference to the colors and style the author wants to use.
Use lighting and neon effects to give the interface a modern and techy look.

## Movement

Add some movement ot the elements so they dont jsut sit statically on the page. Use paralax scrolling, interactive hovers, enticing call to action butoons and any other technique that can give the page a fun and dynamic feel.
